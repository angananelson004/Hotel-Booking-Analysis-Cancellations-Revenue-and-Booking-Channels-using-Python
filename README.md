# Hotel-Booking-Analysis-Cancellations-Revenue-and-Booking-Channels-using-Python
End-to-End Python Data Analysis.
## Tools used
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly
## Project Overview
This project analyses 119,390 hotel booking records from two hotels, a city hotel and a resort hotel, covering arrivals from 1 July 2015 to 31 August 2017. The work was done in Python with pandas, NumPy, Matplotlib, Seaborn and Plotly, in a single Jupyter notebook.
 
The analysis started with a simple comparison of the two hotels and then followed one question: why does the city hotel lose more bookings to cancellation? That led to a closer look at cancellation behaviour, and from there to guest origin, repeat guests, no-shows, sales channels and individual booking agents.
